💡 Recommendation for Your Project

Since you're building this as an interview-focused project, I recommend adding Swagger/OpenAPI documentation as a final enhancement. It takes about 20–30 minutes to integrate and gives you an interactive API documentation page (e.g., http://localhost:5000/api-docs) where interviewers can explore and test all your endpoints directly. It creates a strong professional impression without requiring major changes to your existing codebase.
